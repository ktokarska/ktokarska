### Projects

**Production AI agents inside a regulated insurer** · *CarbonPool*
Architected and shipped two production LLM agents with Claude Code: an applied-research agent for technical project assessment and a due-diligence / KYC agent, each gated on a model-evaluation pipeline I built first. Cut counterparty checks from **several days to under 10 minutes** and moved **~80% of the team** onto AI-augmented workflows. *(Proprietary — no public repo.)*

**UK Fair House-Price Estimator** · [repo](https://github.com/ktokarska/housing_tool_fair_price) · [live demo](https://kasiatokarska.com/house-price-fair-estimate.html)
A valuation tool that reports its own confidence instead of one false-precise number. Runs a **three-method ensemble** — matched comparable sales, £/sq ft from EPC-verified floor area, and a public AVM cross-check — then returns a range and a confidence rating, and **abstains when the methods disagree**. Built with Claude Code on UK open data.

**Remaining Carbon Budget Uncertainty** · [repo](https://github.com/ktokarska/remaining_carbon_budgets)
Code behind Matthews, Tokarska et al. (2021), *Communications Earth & Environment* — an integrated method for quantifying uncertainty in the remaining carbon budget for the Paris Agreement (co-first author). Part of a body of work spanning **24 peer-reviewed papers and 4,000+ citations**. See also [intro-climate-data-analysis](https://github.com/ktokarska/intro-climate-data-analysis) (⭐5).
